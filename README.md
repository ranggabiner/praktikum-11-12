# Resep Dunia

Resep Dunia adalah aplikasi Android untuk menampilkan daftar resep makanan dari API TheMealDB. Aplikasi menampilkan resep dalam bentuk grid dengan gambar, nama makanan, dan kategori, lalu pengguna dapat membuka halaman detail untuk melihat foto resep dan instruksi memasak.

## Fitur Aplikasi

- Menampilkan daftar resep makanan dari internet.
- Menampilkan gambar dan nama resep dalam grid dua kolom.
- Mendukung refresh data dengan swipe refresh.
- Menampilkan halaman detail resep berisi gambar, judul, dan langkah memasak.
- Menyediakan tampilan loading, data kosong, dan tombol coba lagi saat terjadi error.
